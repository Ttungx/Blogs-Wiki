# z.ai / Moonshot 博客来源核验报告（2026-08-11）

由 subagent 实测（curl 直连，代理 127.0.0.1:7897 兜底）。

## z.ai（原 GLM / 智谱 AI 相关品牌）

- `https://z.ai/blog` 当前返回 404，不能作为可枚举列表页。
- 具体文章 URL（例如 `https://z.ai/blog/glm-5.2`）可以访问，但这只能证明单篇页面存在，不能证明存在稳定的官方文章索引。
- `https://z.ai/sitemap.xml` 未发现可用于收录的 `/blog/` 文章 URL；目前未核验出 RSS、分页列表或其他官方枚举入口。
- 因此不再使用 `https://www.zhipuai.cn/zh/news`：该地址属于新闻中心，内容混合公司动态与公告，不符合当前 LLM / Agent / 工程技术收录边界。
- 当前配置：来源 ID `z-ai`，展示地址 `https://z.ai/blog`，`update_mode: dry-run-only`，适配状态“候选”。在发现入口确认前，不自动发现、翻译或持久化文章。

## Moonshot（月之暗面 / Kimi）

- **https://www.kimi.com/blog/**（真实 SSR 博客，9 篇）
- 无 RSS。
- **https://www.kimi.com/sitemap/sitemap-ug-blog.xml**（博客专用 sitemap，9 篇 + 索引，带 lastmod，机器可读日期来源）。
- 文章 URL：`/blog/<slug>`（无尾斜杠、无日期前缀）：agent-swarm / kimi-k2 / kimi-k2-5 / kimi-k2-6 / kimi-k2-thinking / kimi-k3 / kimi-vendor-verifier / perception-bench / worldvqa。
- 官方简体中文：无（仅英文，需模型翻译）。
- 图片：绝对原链（statics.moonshot.cn / kimi-file.moonshot.cn 签名 URL）。
- 无 hreflang；文章页 JSON-LD 有 datePublished。
- 抓取障碍：无（nginx + Next.js，无 WAF）。
- 内容方向：纯技术（LLM 模型、Agent、benchmark），高度匹配。

## 接入结论

- Moonshot 结构最干净（专用 sitemap、零明显噪音），来源 ID 已统一为 `moonshot`，继续保持 active。
- z.ai 暂不接入自动更新；不得把新闻中心或产品文档 changelog 直接当作博客来源。
- 若后续发现 z.ai 官方文章索引，应先新增来源审计报告，验证文章边界、发布日期、正文和图片原链，再决定是否从候选转为正在适配。
