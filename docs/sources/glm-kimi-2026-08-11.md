# GLM / Kimi 博客来源核验报告（2026-08-11）

由 subagent 实测（curl 直连，代理 127.0.0.1:7897 兜底）。

## GLM（智谱 AI / Z.ai）

- `https://z.ai/blog` 已死（404，z.ai 现跳 chat.z.ai 产品页）；`chatglm.cn/blog`、`open.bigmodel.cn/blog` 均为 SPA 空壳。
- 可用官方索引：
  - **https://www.zhipuai.cn/zh/news**（Next.js + Payload CMS，SSR，原生中文；文章 `/zh/news/<数字id>`，无 slug，共 15 篇，无分页）
  - **https://docs.bigmodel.cn/cn/update/new-releases**（模型发布 changelog；有机器可读 `/cn/update/new-releases.md`，每条 `<Update label="2026-06-16" description="...">`）
- 无 RSS（rss.xml 等为 HTML 404 回退假阳性）。
- Sitemap：zhipuai.cn/sitemap.xml 只有 10 个顶层页不含文章；docs.bigmodel.cn/sitemap.xml 覆盖文档。
- 官方简体中文：是（zh 路由原生中文；en 路由多数回退显示中文）。
- 图片：相对路径 `/api/media/file/<file>.png`，需拼接域名绝对化。
- 无 hreflang。
- 建议：`article_paths: ^/zh/news/\d+$`，需排除公司/财经公告（可用列表 tag_zh 过滤）；changelog 需按 `<Update>` 块切分。
- 内容方向：混合（约 1/3 技术前沿：GLM 模型/Agent/端侧；其余公司公告）。

## Kimi（月之暗面 Moonshot AI）

- **https://www.kimi.com/blog/**（真实 SSR 博客，9 篇）
- 无 RSS。
- **https://www.kimi.com/sitemap/sitemap-ug-blog.xml**（博客专用 sitemap，9 篇 + 索引，带 lastmod，机器可读日期来源）。
- 文章 URL：`/blog/<slug>`（无尾斜杠、无日期前缀）：agent-swarm / kimi-k2 / kimi-k2-5 / kimi-k2-6 / kimi-k2-thinking / kimi-k3 / kimi-vendor-verifier / perception-bench / worldvqa。
- 官方简体中文：无（仅英文，需模型翻译）。
- 图片：绝对原链（statics.moonshot.cn / kimi-file.moonshot.cn 签名 URL）。
- 无 hreflang；文章页 JSON-LD 有 datePublished。
- 抓取障碍：无（nginx + Next.js，无 WAF）。
- 内容方向：纯技术（LLM 模型、Agent、benchmark），高度匹配。

## 接入建议

- Kimi 结构最干净（sitemap 完整、零噪音），优先接入。
- GLM 双源：zhipuai.cn/zh/news（原生中文直通）+ docs.bigmodel.cn changelog（条目切分解析），零翻译成本。
- 均按 `dry-run-only` 起步，audit 通过后再转 active。
